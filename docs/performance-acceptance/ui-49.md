## 父级最小复现与根因

### 1. 同实例 remount 不恢复（双引擎，稳定失败）

1. 将带非空实际 VM 的 `VideoDanmakuPanel` 加入 Grid，等待首次引擎创建。
2. `vm.Redraw()`，同一 UI 调用栈切换 `vm.Renderer`，立即从 Grid 移除 panel。
3. 卸载后可 `vm.Initialize(...)`、`vm.UpdatePosition(20)`、`vm.Pause()`。
4. 将**同一个 panel/VM** 加回 Grid，等待实际 Loaded；再 `vm.Redraw()`。

实际：首次 unload 释放两字段并清空 Grid；重新 Loaded 后仍 `dx=false, legacy=false, visuals=0`，`_lastProgress` 仍旧值。每种起始引擎连续三次重挂一致；probes 额外等 Sample 并调用公开 Redraw 仍为 0。不是重复层数通过，而是订阅/引擎丢失。

证据：[DirectX 第一次重新挂载 PNG](evidence-49-ui/DirectX-near/18-remount.png)、[Win2D 对应 PNG](evidence-49-ui/Win2D-near/18-remount.png)、[公开 Redraw 后 PNG](evidence-49-ui/probes/DirectX-remount-public-redraw.png)，同名 UIA 文件与 [events.jsonl](evidence-49-ui/events.jsonl)。失败测试 `DirectX_RepeatedRemountRestoresRenderer`、`Win2D_RepeatedRemountRestoresRenderer`、`BothEngines_RemountPublicRedrawRestoresRenderer`。

根因：实际 NuGet `LayoutUserControlBase.OnUnloaded` 首次卸载移除自己的 Loaded/Unloaded 处理器，后续不会再调用生产 override。现有 [IL 证据](evidence-50-53/base-lifecycle-il.txt) 的 remove_Loaded/remove_Unloaded 与本次 DLL 哈希 `BC68250223D14F53F87082B35428EE2144B7333D124A09AF2A172BC389A232B7` 对应。此处 IL 为已有证据复核，不冒称新反编译。#49 当前源码只有 `OnControlLoaded` override，构造函数与 XAML 没有独立重复 Loaded 接线；override 不能抵消基类自注销。需要父级修复并重新验收，本分支不改生产。

### 2. 暂停 seek 恢复了引擎运行（双引擎，重复失败）

最小输入：真实 panel 已 loaded/engine ready，`vm.UpdatePosition(2); vm.Pause(); vm.UpdatePosition(20);`，再从 20 回到 2。**不额外调用 Resume**。

实际 VM 的 `IsPaused` 一直 true，但两引擎 `_render._isPaused=false`。DirectX 最终矩阵 Pause/Sample 的 stopwatch 恒为 386.7865 ms 且 IsRunning=false；SeekForward 后 387.1285 → 1517.272 ms 且 IsRunning=true。独立 probes 再现：暂停 1604.5044 ms 恒定，seek 后 1604.5811 → 2042.7151 ms。Win2D 在矩阵与 probes 两轮均从 true 变 false，并在稍后 Sample 仍 false。普通 Pause 能设置 true；这不是 VM 状态断言替代 renderer 状态。

失败测试 `DirectX_PausedSeekPreservesPause`、`Win2D_PausedSeekPreservesPause`。根因链：真实 `UpdatePosition` 发 ProgressChanged → panel `OnProgressChanged` → `UpdateDanmakuTime` → 包的异步 UpdateTime/隐式 Seek → Resume；普通进度路径没有恢复 VM 暂停状态。Redraw 的尾部 Pause 也不构成异步 seek 完成后的保证：probes 从 DirectX 暂停位置 20 切到 Win2D，立刻/稍后 Sample 都为 false（`DirectXToWin2D_PausedSwitchRestoresPause` 失败）。反向切到 DirectX 的本次样本为 true；不泛化为所有时序正确。

直接 seek 的空白截图不能证明移动；上述失败由实际引擎暂停标志和 DirectX 时间戳推进支持。可见对照：[DirectX 普通暂停 A](evidence-49-ui/probes/DirectX-paused-a.png)/[B](evidence-49-ui/probes/DirectX-paused-b.png) 中相同文字位置未变，seek 后画面为空。Win2D 普通暂停后部分内容消失，本次没有定位其根因，不能签署视觉暂停保持。
