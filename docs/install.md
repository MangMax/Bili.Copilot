# 安装应用

## 设备需求

### 桌面客户端

1. Windows 操作系统。
2. 操作系统版本在 Win10 19041 以上。

目前桌面客户端基于 Windows App SDK 构建，仅支持 Windows 桌面操作系统。Microsoft Store 版本由上游项目发布；本仓库的独立维护版本通过 GitHub Releases 分发。

### 从 GitHub Releases 安装

前往 [Releases](https://github.com/MangMax/Bili.Copilot/releases) 下载最新的 `BiliCopilot_*.zip`，完整解压后双击 `Install.cmd`。

首次安装会请求管理员权限导入随包证书；应用本身按当前用户安装，不需要开启开发者模式。
