## What to build

默认推荐/热门内容与侧栏分区独立加载，分区接口缓慢或失败不拖住首屏。

证据：Popular 初始化先等待 LoadPartitions，再延迟 200ms，之后才选择栏目并开始加载视频；PR #27 保留了这条初始化路径。

## Acceptance criteria

- [ ] 保存栏目为推荐/热门时，在分区请求完成前即可请求并显示该栏目。
- [ ] 恢复指定分区排行仍等待所需目录，目录失败或目标消失时明确回退，不出现错栏目结果。
- [ ] 去除首屏路径固定等待，用控件就绪和状态协调防止布局重入。
- [ ] 快速切换栏目、刷新与恢复最后选择均正确，兼容已有增量刷新/撤销，不重写这些功能。
- [ ] 记录慢分区接口下的首批卡片展示时间与请求时序。
- [ ] 附上本票相关验证证据与未验证项；不以静态分析冒充实机验收。
