## What to build

连续输入仅在短暂停顿后获取联想，旧结果不覆盖新输入，正常取消不刷错误日志。

证据：用户输入事件直接执行 ReloadSuggestions；提交后的 600ms 抑制不是输入防抖。现有请求虽被取消但没有结果版本检查，通用异常按错误记录。

## Acceptance criteria

- [ ] 普通输入采用短暂停顿合并，默认可先用 250ms；同窗口内连续输入只请求最终关键词。
- [ ] 新输入立即使旧结果失效；取消或迟到结果不弹出过期联想，不记录正常取消为错误。
- [ ] 保留 IME 组合输入、选择联想提交、空输入获焦推荐和区域搜索行为。
- [ ] 卸载/取消后不再提交待执行联想，真实网络错误仍可诊断。
- [ ] 附上本票相关验证证据与未验证项；不以静态分析冒充实机验收。
