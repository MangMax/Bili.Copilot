## What to build

证据：每次 ViewChanged/SizeChanged 都提交低优先级回调，未合并；下游部分页面已有防重复加载，因此不宣称已发生重复请求。

## Acceptance criteria

- [ ] 同一控件同时至多存在一个待执行触底检查，以执行时位置判定。
- [ ] 卸载后不执行加载；重新加载可正常触发，命令不可执行时不强行执行。
- [ ] 短列表能继续补齐视口，快速滚动、到末页与窗口缩放无漏页或持续空转。
- [ ] 附上本票相关验证证据与未验证项；不以静态分析冒充实机验收。
