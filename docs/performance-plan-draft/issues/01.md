## Acceptance criteria

- [ ] 固定分片流在合并刷新期间保留文本完整性与顺序，结束时立即提交最后一批，不逐分片全量重建 Markdown。
- [ ] 取消、切换来源、重新生成后旧回调不追加文本、不清空新回复、不修改新会话生成状态。
- [ ] 流式期间允许纯文本或稳定块展示，最终表格、代码块、链接与复制答案行为正确；不改模型提供商协议。
- [ ] 同一分片重放记录变更前后 UI 提交次数、分配量与响应延迟，保留测量条件，不承诺未经测量的收益。
- [ ] 附上本票相关验证证据与未验证项；不以静态分析冒充实机验收。

## Testing decisions

在生成会话的输入流→可见结果边界验证，复用既有代次守卫与批量提交测试思路；用受控分片与可推进时间，避免真实模型调用和固定 sleep。真实 WinUI 验收最终格式与取消。
