## What to build

等待 BBDown 下载完成时不长期占用线程池线程，成功后按设置打开目录并释放进程对象。

证据：后台 Task.Run 中调用 Process.WaitForExit，Process 对象没有 using；默认下载后打开目录会进入等待。

来源：性能审查 F10（下载）；基线为 4344ae756344f3ed6f1c11bd3216320b9143996f。行为机制已核实，实际耗时/内存收益未测。实施前复查最新分支及相关 PR，避免重复修复。

## Acceptance criteria

- [ ] 使用异步进程等待并确定性释放 Process 资源，不改变子进程的下载方式。
- [ ] 仅成功完成且设置允许时打开目录；启动失败或非零退出不误报成功。
- [ ] 外部 BBDown、复制命令模式及关闭主窗口后的现有下载语义保持，不新增杀进程策略。
- [ ] 多次下载完成后记录句柄与等待线程，测试使用无凭据短命子进程或受控替身。
- [ ] 附上本票相关验证证据与未验证项；不以静态分析冒充实机验收。
