## What to build

清空或关闭 Markdown 面板时释放自身内容，不主动要求整个应用执行全堆 GC。

证据：MarkdownTextBlock 的 Clean 由清空文本及 Unloaded 触发，直接调用 GC.Collect。

来源：性能审查 F02；基线为 4344ae756344f3ed6f1c11bd3216320b9143996f。行为机制已核实，实际耗时/内存收益未测。实施前复查最新分支及相关 PR，避免重复修复。

## Acceptance criteria

- [ ] 普通文本清空和卸载路径不触发应用主动发起的全堆回收。
- [ ] 再次打开及重新赋值仍能正确显示文本、链接和图片。
- [ ] 反复清空/关闭的性能采样记录 GC 暂停及存活对象；不以立即降低工作集为验收标准。
- [ ] 附上本票相关验证证据与未验证项；不以静态分析冒充实机验收。

## Testing decisions
