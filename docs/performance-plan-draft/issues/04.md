## What to build

活动弹幕引擎已就绪时立即安排重绘；快速设置变更只应用当前有效状态。

证据：单引擎模式下另一个引擎字段为 null，Redraw 的逻辑或条件恒使其等待 500ms，等待后的请求也未合并。

## Acceptance criteria

- [ ] 分别启用 Win2D 和 DirectX 时，已就绪引擎不因未启用引擎为空而固定等待 500ms。
- [ ] 连续重绘请求合并；引擎切换、卸载后过期请求不会调用已释放实例。
- [ ] 暂停状态、当前位置、样式与弹幕内容正确，不为性能改变可见效果。
- [ ] 附上本票相关验证证据与未验证项；不以静态分析冒充实机验收。

## Testing decisions

真实控件验收两种引擎的启动、切换、暂停、重绘与卸载；只有需要调度逻辑时抽取单一重绘会话边界，不增加全局调度框架。
