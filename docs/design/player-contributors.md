# 联合投稿头像名称列表

视频播放页的信息区在多人投稿时，原本把主投稿人与合作者姓名拼成一段文字（`A、B、C`）。现在改为：上方保留主投稿人的头像与关注操作，下方以横向人员列表展示合作者；列表可左右滚动，也可以展开成两列查看全部。适用范围仅限 UGC 视频播放页信息区，不改动视频卡片与 PGC/番剧页面。

## 布局与视觉

- 列表位于 UP 主区域与统计行之间，与作者区共用同一条左缘：区块不设外边距，标题与首列头像各内缩 4 DIP；上方作者区仍使用现有控件与负边距。
- 默认是单行横向列表：每格 160 DIP、格间距 8 DIP，360 DIP 侧栏一次显示两格，超出部分左右滚动；收起状态高度只有一行。
- 标题行只保留「展开 / 收起」按钮，不再放滚动箭头，因此滚动状态变化不会改变标题行高度，列表和下方信息不会上下跳动。
- 左右滚动按钮是 FlipView 式的竖条：32 DIP 宽、与列表行同高、贴在列表左右边缘并叠在内容上方，使用次级控件底色与居中 chevron；起点只显示右侧竖条，末尾只显示左侧竖条，内容不需要滚动时都不显示。竖条不参与布局，出现或消失不会改变列表宽高。
- 展开后切换为两列人员网格（每格 160 DIP、列间距 8 DIP、行间距 2 DIP），展开按钮变为「收起」并把箭头收起；再次点击恢复单行。
- 展开 / 收起使用 200 ms 缓出动画：列表高度从当前高度过渡到目标高度，新内容同时淡入，下方统计与简介随高度平滑移动；横向列表在切换时回到起点，避免展开后从中间内容开始。关闭系统动画时直接切换，不播放过渡。
- 每格是与作者区同构的人员条目：32 DIP 圆形头像，右侧名称 13 DIP SemiBold、角色用 Caption 层级三级色放在名称下方；名称与角色单行截断，完整姓名作为提示。没有角色时第二行隐藏。
- 条目内边距 4 DIP，悬停为整格原生浅底与 4 DIP 圆角；点击任意位置进入用户空间。

## 数据与状态

- 数据来自内核 `VideoInformation.Collaborators`；`CollaboratorListBuilder` 按接口顺序去重（以用户 Id 为准）、排除无名称条目与主投稿人。
- 主投稿人不出现在列表里；`UpName` 只显示主投稿人姓名，资料缺失时才退回原来的姓名拼接。
- 条目点击使用合作者自带的 `UserProfile` 打开用户空间，资料不全时由用户空间页面按 Id 补全。
- 切换视频时列表重置为收起状态、滚动位置回到起点；只有三位及以上合作者时显示展开按钮，列表为空时整个区块折叠。

## 可访问性与测试

- 条目提供用户名自动化名称、用户 Id 自动化 Id，角色同时作为可见文本与 `HelpText`；滚动按钮提供「向左 / 向右查看合作者」名称，展开按钮随状态切换「展开 / 收起」名称，均为键盘可达按钮。
- 新增四个本地化文案：`CollaboratorListExpand`、`CollaboratorListCollapse`、`CollaboratorListScrollLeft`、`CollaboratorListScrollRight`，由调用方传入控件，控件本身不读取资源。
- `CollaboratorListBuilder` 的排除主投稿人、去重、忽略空名称、保留角色与顺序行为由 `CollaboratorListBuilderTests` 覆盖。
- UI 工程按默认阻断口径构建（WinUI 分析器 warning 为 0）。
