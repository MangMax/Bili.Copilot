# 用户空间

用户要求在 WinUI 风格下增强沉浸感，并显示真实头像与 banner。适用范围为用户空间页面，不改变全局导航或共享视频卡片规范。本轮以用户对首版的反馈为准，替换原先的紧凑资料卡方案。

## 布局与视觉

- 使用通栏真实空间 banner，背景延伸覆盖整个资料区。宽布局顶部留出 240 DIP、紧凑布局 180 DIP，背景实际高度跟随资料区测量结果；下缘以主题渐变融入页面底色。背景图使用 UniformToFill，自适应裁切；无图时回退为主题表面。
- 104 DIP 头像配合 4 DIP 主题底色边框，向上跨接背景区 40 DIP，建立空间归属感。头像与背景复用应用现有的可异步加载、响应尺寸变化的图片组件。
- 昵称采用 Title 层级，等级紧邻昵称；简介最多两行，完整内容可通过提示查看，UID 可复制。统计在宽布局右侧，低于 760 DIP 时独占下一行。
- 资料区取消卡片外框，水平留白 28 DIP；分区与操作采用原生 SelectorBar、ToggleButton 和 Button。紧凑布局收起操作文字并保留提示和自动化名称。
- 主题颜色、圆角、图标和控件状态沿用应用已有 WinUI 资源。资料文字前叠加随深浅主题变化的渐变遮罩，降低底图对可读性的影响；动效采用原生控件反馈。
- 内容区保留现有虚拟化、增量加载和卡片模板。

## 滚动与视差

- 每个分区的资料、导航与内容位于同一个原生 ScrollView 中，自然滚动。滚动条使用完整原生轨道，从页面顶部开始。
- 封面是页面底层的独立背景，高度比实测页头多 240 DIP，延伸到首排内容；资料与导航保持透明，没有单独的背景接缝。
- 图片以内容 45% 的速度上移，页面底色渐变则随内容等速上移，从下方向上覆盖图片；在渐变完全不透明处裁切图片，避免滚动时露出封面底边。Composition 表达式绑定原生滚动位置，不逐帧修改布局。
- 关闭系统动画时背景与内容等速滚动。滚轮、触控和键盘均由原生滚动容器处理，不转发滚轮事件。
- 切换分区或搜索后只绑定一次当前滚动容器；页面卸载时解绑尺寸事件并停止背景动画。列表继续保留虚拟化、增量加载、空状态和加载状态。

## 数据与状态

- 现有资料请求附带 `photo=true`，内核将 `space.l_img` 映射为可空 `UserCard.Banner`，头像继续来自 `card.face`。
- 页面接收用户参数后自动加载资料；加载过程保留用户名与原生头像占位，显示进度提示。
- 资料失败显示内联 InfoBar 和重试，内容区仍可使用；统计只在资料取得后出现，不用零值伪装加载结果。
- 资料请求继续使用页面目标代次和取消令牌；旧请求不得写入新用户的资料、加载状态或失败提示。
- 关注按钮显示关注状态，并提供自动化名称；紧凑模式保留提示和键盘操作。
